# NormControl KB

**База знаний для нормоконтролёра.** Инструмент для проверки чертежей и документов по ГОСТ с быстрым доступом к типовым ошибкам, стандартам и примерам.

## Проблема

Нормоконтролёр ежедневно проверяет десятки чертежей и документов. Каждая ошибка требует поиска ГОСТа, проверки смежных ошибок, сверки с примерами. Без единой базы это занимает часы.

## Решение

Единая база знаний на **Obsidian** с публикацией на **GitHub Pages** через **Quartz**.

### Ключевые особенности

- **Двусторонние ссылки** между ошибками, ГОСТами и документами
- **Быстрый поиск** по всей базе
- **Граф знаний** — визуализация связей
- **Доступ через браузер** — не нужно ставить софт на рабочем ПК
- **Автоматическая публикация** через GitHub Actions

## Технологии

- **Obsidian** — редактор Markdown
- **Quartz** — генератор статических сайтов
- **GitHub Pages** — хостинг
- **GitHub Actions** — CI/CD

## Как запустить локально

```bash
git clone https://github.com/<логин>/normcontrol-kb.git
cd normcontrol-kb
npm install
npx quartz build --serve
```

Сайт откроется на <http://localhost:8080>.

Собрать статику без сервера:

```bash
npx quartz build
```

Результат сборки складывается в папку `public/`.

## Структура базы

```
content/
├── index.md            главная страница
├── 00_Инбокс.md        быстрые записи в течение дня
├── 01_Вопросы.md       открытые вопросы
├── 02_Ошибки/          каталог типовых ошибок по категориям
├── 03_ГОСТы/           конспекты стандартов
├── 04_Документы/       чек-листы проверки по типам документов
├── 05_Примеры/         сканы «плохо/хорошо»
└── 99_Шаблоны/         шаблоны заметок
```

## Как добавить материал

1. Откройте как хранилище (vault) папку `C:\Normcontrol-KB\content` — это только заметки, без кода Quartz и `node_modules`, поэтому поиск и граф не засоряются лишним.
2. Быстрая запись — в `00_Инбокс.md`, разбор — раз в неделю.
3. Новая ошибка — по шаблону `99_Шаблоны/Шаблон_ошибки.md`.
4. Новый стандарт — по шаблону `99_Шаблоны/Шаблон_ГОСТа.md`.
5. Внутри заметок связывайте материалы ссылками `[[Имя_заметки]]` — связи дают граф и контекст.

## Как опубликовать изменения

```bash
git add .
git commit -m "Обновление базы"
git push
```

После push GitHub Actions сам соберёт сайт и выложит его на GitHub Pages (2–5 минут).

## Сайт

После первой публикации база доступна по адресу:

```
https://<логин>.github.io/normcontrol-kb/
```

Проверить статус сборки: вкладка **Actions** в репозитории.

## Важно про данные

База публичная. Перед добавлением материалов удаляйте персональные данные, названия организаций, подписи и всё, что относится к реальным заказам. Проверяйте это при добавлении примеров в `05_Примеры/`.
