# База знаний нормоконтролёра

Открытая база знаний по нормоконтролю конструкторской документации (ЕСКД): типовые ошибки, требования ГОСТов, чек-листы проверки и примеры оформления.

> [!note] Как пользоваться
> Разделы 02–04 связаны двусторонними ссылками: из ошибки можно перейти к ГОСТу, из ГОСТа — к списку ошибок по нему, из документа — к чек-листу проверки. Поиск — в левой панели сверху, граф связей — в правой панели (кнопка разворота открывает его на весь экран).

## Как вести базу

1. Всё, что непонятно на проверке, — сначала в [[00_Инбокс|инбокс]] одной строкой.
2. Раз в неделю разобрать инбокс: оформить ошибку по [[99_Шаблоны/Шаблон_ошибки|шаблону ошибки]] или вопрос в [[01_Вопросы|вопросы]].
3. Новый ГОСТ — по [[99_Шаблоны/Шаблон_ГОСТа|шаблону ГОСТа]], новый документ — по [[99_Шаблоны/Шаблон_документа|шаблону документа]].
4. Не забывать про смежные ошибки: именно связи между заметками дают эффект базы, а не отдельные записи.

## Редактор базы (самый простой способ)

Откройте в браузере **[Редактор базы нормоконтролёра](https://frinog1-a11y.github.io/normcontrol-kb/static/admin/)** — это обычная форма: слева список заметок, справа поля «Название», «Краткое описание», «Теги» и текст заметки. Достаточно нажать «Сохранить» — сайт пересоберётся сам за 1–2 минуты.

## Если редактор не открывается (на рабочем ПК закрыт GitHub API)

В некоторых рабочих сетях заблокирован `api.github.com` — тогда веб-редактор не сможет войти. В этом случае внизу **каждой** страницы базы есть две кнопки:

- **✎ Править эту заметку на GitHub** — открывает эту же заметку в редакторе GitHub;
- **＋ Создать новую в этой папке** — создаёт заметку рядом в этой же папке.

Порядок: изменить текст → **Commit changes** → **Commit changes** (подтвердить). Через 1–2 минуты правка появится на сайте.

## Как править базу через GitHub (запасной способ, только браузер)

Ставить софт не нужно: правки делаются прямо на GitHub, а сайт пересобирается автоматически.

1. Откройте `github.com/frinog1-a11y/normcontrol-kb` (для полноценного редактора — `github.dev/frinog1-a11y/normcontrol-kb`, это VS Code прямо в браузере).
2. Зайдите в папку `content/`, выберите заметку и нажмите значок карандаша.
3. Внесите правку → **Commit changes** → **Commit directly to the main branch**.
4. Через 2–5 минут правка появится на сайте (ход сборки видно во вкладке **Actions**).

Новая заметка: **Add file → Create new file** внутри нужной папки `content/…`, имя файла без пробелов (например, `Неверный_порядок_записи.md`), содержимое — по [[99_Шаблоны/_index|шаблону]]. Ссылки `[[Имя_заметки]]` набираются вручную, имя должно точно совпадать с именем файла без расширения.

Картинки: **Add file → Upload files** в папку [[05_Примеры/_index|05_Примеры]] → в заметке ссылка `![[05_Примеры/Плохо/спецификация_01.png]]`.

> [!warning] База публичная
> Перед публикацией убирайте персональные данные, названия организаций, номера реальных заказов и подписи.

> [!warning] Оговорка
> Заметки — рабочие конспекты, а не официальный текст стандарта. Перед применением сверяйте формулировки и номера пунктов с действующей редакцией ГОСТа (см. ссылки в каждой заметке ГОСТа).
