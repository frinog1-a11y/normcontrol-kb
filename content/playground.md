# 🎨 Песочница

Ты — Астроном. Здесь ты создаёшь созвездия из звёзд ночного неба.

## Что можно делать

- **Клик по фону** — зажечь новую звезду
- **Протяжка мышью** — нарисовать линию между звёздами
- **💾 Сохранить** — сохранить созвездие с именем
- **🧹 Сброс** — очистить поле
- **🎲 Случайное** — случайное созвездие из шести линий

> [!note] Прогресс «Астронома»
> Клики по фону на любой странице открывают созвездия: ✨ линии между звёздами (5), 🦉 Сова (15), 🦊 Лиса (30), 🐻 Медведь (45), 🎨 песочница (60), 🌌 свободный полёт — 200 звёзд (100). Прогресс хранится в браузере.
