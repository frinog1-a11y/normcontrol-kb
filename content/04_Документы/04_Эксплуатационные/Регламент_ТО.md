# Регламент ТО

**ГОСТ:** [[ГОСТ_2.601-2019]]
**Категория:** [[04_Документы/04_Эксплуатационные/_index|Эксплуатационные документы]]
**Теги:** #документ #эксплуатационные

## Что это

Документ, устанавливающий виды, периодичность, объём и порядок выполнения работ по техническому обслуживанию изделия, а также требования к исполнителям и средствам контроля.

Регламент — основа для планирования ТО, поэтому расхождения в периодичности дороже всего: работы или не делают, или делают лишние.

## Когда применяется

На изделия, требующие регулярного технического обслуживания по установленному графику.

## Основные разделы / элементы

- Виды и периодичность технического обслуживания
- Перечень и объём работ по каждому виду
- Требования к средствам контроля и исполнителям
- Указания по безопасности при выполнении работ

## Все типовые ошибки по этому документу

### По оформлению

- Обозначение и наименование расходятся с ведомостью ЭД — [[Несоответствие_обозначения_документа]]
- Реквизитная часть ЭД не оформлена — [[Неверная_структура_электронного_документа]]
- Подписи исполнителей оформлены без фамилий и дат — [[Неверное_оформление_электронной_подписи]]

### По содержанию

- Периодичность ТО противоречит указаниям руководства по эксплуатации
- Объём работ не обеспечивает требования по надёжности из ТУ
- Не указаны средства измерений и критерии отбраковки

## Чек-лист проверки

- [ ] Виды и периодичность ТО согласованы с РЭ и ТУ
- [ ] Объём работ описан однозначно, указаны средства контроля
- [ ] Указаны требования безопасности при выполнении работ
- [ ] Есть ссылки на [[04_Документы/05_Ремонтные/Руководство_по_ремонту|руководство по ремонту]] для ремонтных работ
