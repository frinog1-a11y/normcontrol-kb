# Ведомость ЭД

**ГОСТ:** [[ГОСТ_2.601-2019]]
**Категория:** [[04_Документы/04_Эксплуатационные/_index|Эксплуатационные документы]]
**Теги:** #документ #эксплуатационные

## Что это

Документ, перечисляющий эксплуатационные документы, входящие в комплект изделия: руководство по эксплуатации, формуляр, паспорт и другие. Оформляется таблицей с основной надписью по форме 2.

По ведомости проверяют комплектность ЭД: чего не хватает в поставке.

## Когда применяется

Обязательный документ при поставке изделий, на которые выпускаются эксплуатационные документы.

## Основные разделы / элементы

- Табличная часть: обозначение документа, наименование, количество экземпляров, примечание
- Порядок записи — по возрастанию обозначений
- Основная надпись по форме 2

## Все типовые ошибки по этому документу

### По оформлению

- Обозначения расходятся с самими эксплуатационными документами — [[Несоответствие_обозначения_документа]]
- Порядок записи нарушен — [[Неверный_порядок_разделов_спецификации]]
- Ведомость оформлена без требуемых граф

### По содержанию

- В ведомости указаны документы, которых нет в комплекте, и наоборот
- Количество экземпляров не соответствует фактической поставке

## Чек-лист проверки

- [ ] Обозначения и наименования совпадают с самими ЭД
- [ ] Все документы комплекта перечислены, лишних нет
- [ ] Количество экземпляров указано верно
- [ ] Основная надпись по форме 2
