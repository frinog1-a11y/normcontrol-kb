# Схема комбинированная

**ГОСТ:** [[ГОСТ_2.701-2008]]
**Категория:** [[04_Документы/03_Схемы/_index|Схемы]]
**Теги:** #документ #схемы

## Что это

Схема, на которой изображены элементы и связи разных видов: например, электрические и гидравлические, механические и пневматические. Вид схемы обозначается буквой С, тип — цифрой.

## Когда применяется

Когда связи между частями изделия разных физических принципов нужно показать на одном документе, чтобы не потерять взаимодействие (например, электро-гидравлический привод).

## Основные разделы / элементы

- Элементы и связи разных видов с УГО по соответствующим стандартам
- Позиционные обозначения и перечень элементов
- Пояснения, какие виды связей показаны (в ТТ)
- Основная надпись по форме 1

## Все типовые ошибки по этому документу

### По оформлению

- УГО элементов разных видов выполнены непоследовательно — [[Неверное_УГО_элемента]]
- Перечень элементов без деления по видам или отсутствует — [[Отсутствует_перечень_элементов]]
- Не указано, какие виды связей изображены

### По содержанию

- Схема расходится с однотипными схемами комплекта (Э3, Г3)
- Не указаны параметры элементов разных видов

## Чек-лист проверки

- [ ] Код С указан в обозначении документа и в основной надписи
- [ ] УГО элементов соответствуют своим видам схем
- [ ] Перечень элементов разделён по видам связей
- [ ] Указано, какие виды связей объединены на схеме
- [ ] Данные согласованы с однотипными схемами комплекта
