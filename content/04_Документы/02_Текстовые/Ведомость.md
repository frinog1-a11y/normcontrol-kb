# Ведомость

**ГОСТ:** [[ГОСТ_Р_2.106-2019]]
**Категория:** [[04_Документы/02_Текстовые/_index|Текстовые документы]]
**Теги:** #документ #ведомость

## Что это

Текстовый документ, содержащий перечень сведений об изделии: ведомость документов, ведомость покупных изделий, ведомость держателей подлинников, ведомость эксплуатационных документов.

Оформляется таблицей на листах формата А4 с основной надписью по форме 2, при большом объёме — с продолжением на последующих листах (форма 2а).

## Когда применяется

Когда сведения об изделии удобнее вести таблицей, а не отдельными документами: комплектность, состав покупных изделий, состав ЭД.

## Основные разделы / элементы

- Табличная часть с графами, установленными стандартом для конкретной ведомости
- Порядок записи: по возрастанию обозначений документов или позиций
- Основная надпись по форме 2 (для последующих листов — 2а)

## Все типовые ошибки по этому документу

### По оформлению

- Порядок записи нарушен: записи идут не по возрастанию обозначений — [[Неверный_порядок_разделов_спецификации]]
- Обозначения в ведомости расходятся с самими документами — [[Несоответствие_обозначения_документа]]
- Номера листов и их общее число не соответствуют факту

### По содержанию

- В ведомости указаны документы, которых нет в комплекте, и наоборот
- Наименования записей отличаются от наименований самих документов

## Чек-лист проверки

- [ ] Обозначения и наименования совпадают с самими документами
- [ ] Порядок записи — по возрастанию обозначений
- [ ] Графы заполнены полностью, лишних граф нет
- [ ] Основная надпись по форме 2, номера листов верные
