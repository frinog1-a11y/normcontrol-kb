# Ведомость ремонтных документов

**ГОСТ:** [[ГОСТ_2.602-2016]]
**Категория:** [[04_Документы/05_Ремонтные/_index|Ремонтные документы]]
**Теги:** #документ #ремонтные

## Что это

Документ, перечисляющий ремонтные документы, входящие в комплект изделия: руководство по ремонту, каталоги деталей, нормы расхода запасных частей и другие. Оформляется таблицей с основной надписью по форме 2.

## Когда применяется

При поставке изделий, на которые выпускаются ремонтные документы, и при организации ремонтных работ.

## Основные разделы / элементы

- Табличная часть: обозначение документа, наименование, количество экземпляров
- Порядок записи — по возрастанию обозначений
- Основная надпись по форме 2

## Все типовые ошибки по этому документу

### По оформлению

- Обозначения расходятся с самими ремонтными документами — [[Несоответствие_обозначения_документа]]
- Порядок записи нарушен — [[Неверный_порядок_разделов_спецификации]]
- Форма основной надписи не соответствует типу документа — [[Неверное_заполнение_масштаба]]

### По содержанию

- В ведомости указаны документы, которых нет в комплекте, и наоборот
- Количество экземпляров не соответствует фактической поставке

## Чек-лист проверки

- [ ] Обозначения и наименования совпадают с самими документами
- [ ] Перечислены все ремонтные документы комплекта
- [ ] Количество экземпляров указано верно
- [ ] Основная надпись по форме 2
