# Неверные обозначения сварных швов

**Категория:** [[02_Ошибки/Обозначения/_index|Обозначения]]
**ГОСТ:** [[ГОСТ_2.312-72]]
**Теги:** #ошибка #обозначения

## Как выглядит ошибка

В обозначении шва нет ссылки на стандарт на типы швов, не указаны катет и длина, вспомогательные знаки стоят не на своём месте. Обозначение читается с обратной стороны полки, из-за чего смысл меняется.

Для двусторонних швов знаки указаны только с одной стороны полки.

## Как правильно

Обозначение шва — по ГОСТ 2.312-72: вспомогательные знаки, обозначение стандарта на типы швов, размеры (катет, длина, шаг для прерывистых швов). Полку линии-выноски располагают так, чтобы запись читалась однозначно; двусторонние швы обозначают с обеих сторон полки.
