# Неверный код документа

**Категория:** [[02_Ошибки/Основная_надпись/_index|Основная надпись]]
**ГОСТ:** [[ГОСТ_Р_2.201-2023]]
**Документ:** [[05_Элементы_оформления/Основная_надпись|Основная надпись]]
**Теги:** #ошибка #основная_надпись

## Как выглядит ошибка

В обозначении стоит код, не соответствующий виду документа: сборочный чертёж обозначен без кода СБ, схема — без кода вида и типа (Э3, Г3, П3, К3), текстовые документы — кодом чертежа. Либо код пропущен вовсе.

Отдельно: код указан «по старой памяти» — по отменённой редакции стандарта.

## Как правильно

Код документа — по ГОСТ Р 2.201-2023 и ГОСТ Р 2.102-2023: два знака для чертежей (СБ — сборочный, ВО — общего вида, ГЧ — габаритный, МЧ — монтажный), буквенно-цифровой код схемы (Э3, Г3, П3, К3, С3), буквенный код текстового документа (ТУ, ПЗ, РР, ПМ).

Код сверяют с фактическим содержанием документа, а не с его прежним вариантом.
