## Типовые ошибки категории

- Неверный порядок записи разделов: разделы спецификации идут в установленной последовательности (документация, комплексы, сборочные единицы, детали, стандартные изделия, прочие изделия, материалы, комплекты).
- Наименование раздела написано в графе «Наименование» вразрядку/с прописной буквы вместо требуемого оформления заголовка.
- Графа «Кол.» заполнена там, где она не заполняется (например, для документов), или не заполнена для деталей.
- Позиции в разделе «Стандартные изделия» записаны не в порядке возрастания обозначения стандарта, а по алфавиту наименования.
- Не указано обозначение документа для записей в первом разделе (документация) либо оно расходится с основной надписью самого документа.
- Записи отсортированы «как удобно», без группировки по разделам.
- Не заполнены графы основной надписи спецификации (форма 2) или указан не тот формат.

## Как проверять

1. Разделы — в правильной последовательности, каждый с заголовком.
2. Внутри раздела — порядок по возрастанию обозначений.
3. Состав спецификации сверяется с чертежом: все позиции с чертежа есть в спецификации и наоборот.
4. Графы «Кол.», «Примечание» заполнены по правилам.
5. Обозначение спецификации = обозначение изделия + код документа.
