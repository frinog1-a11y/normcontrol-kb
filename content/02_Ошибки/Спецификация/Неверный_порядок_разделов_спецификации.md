# Неверный порядок разделов спецификации

**Категория:** [[02_Ошибки/Спецификация/_index|Спецификация]]
**ГОСТ:** [[ГОСТ_Р_2.106-2019]]
**Теги:** #ошибка #спецификация

## Как выглядит ошибка

Разделы идут «как удобно»: детали раньше сборочных единиц, материалы в середине списка, стандартные изделия в конце. Внутри раздела записи отсортированы по алфавиту наименования вместо возрастания обозначения.

Отдельно: пустые разделы либо разделы без заголовков — границы групп не видны.

## Как правильно

Порядок разделов: документация → комплексы → сборочные единицы → детали → стандартные изделия → прочие изделия → материалы → комплекты. Раздел включают, только если в нём есть записи.

Внутри раздела — по возрастанию обозначения; в «Стандартных изделиях» — по возрастанию обозначения стандарта, а не по алфавиту.
