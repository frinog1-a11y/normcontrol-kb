# Отсутствие шероховатости

**Категория:** [[02_Ошибки/Чертёж_общие/_index|Чертёж общие]]
**ГОСТ:** [[ГОСТ_2.309-73]]
**Теги:** #ошибка #чертёж_общие

## Как выглядит ошибка

Знаки шероховатости не проставлены вовсе, либо указаны только для части поверхностей: исполнитель не знает, какую чистоту обработки обеспечить. Часто вместе с этим отсутствует и указание способа обработки.

Обратная ошибка — знак стоит, а параметр шероховатости не указан: проверять нечего.

## Как правильно

Шероховатость указывают для всех обрабатываемых поверхностей. Обозначение — по ГОСТ 2.309-73, с параметром (Ra или Rz) и числовым значением. Если шероховатость одинакова для группы поверхностей, её указывают один раз в правом верхнем углу чертежа.

Для поверхностей, которые не обрабатываются, знак не ставят.
