## 2. Как это работает для жены (главный сценарий)

1. Открывает <https://frinog1-a11y.github.io/normcontrol-kb/add-note> (или жмёт «✏ Добавить заметку» под заголовком любой страницы).
2. Заполняет одно поле свободным текстом → создаётся issue по шаблону `new-note.yml`.
3. Workflow `.github/workflows/deploy.yml` (job `from-issue`) запускается **только для задач от `frinog1-a11y`**, отправляет текст в ИИ (DeepSeek), получает Markdown заметки, кладёт файл в `content/`, коммитит «Из задачи #N» и пушит.
4. Сборка Quartz + деплой на Pages → заметка появляется на сайте через 1–2 минуты.
5. Задача закрывается; на доске <https://github.com/users/frinog1-a11y/projects/1> уходит в Done (**доска пока приватная** — см. «Открытые вопросы»).

## 3. Команды (Windows, cmd)

```cmd
cd /d C:\Normcontrol-KB
npx tsc --noEmit                 :: типы
npx prettier --write <файлы>     :: формат (перед коммитом)
npx quartz build                 :: сборка в public\ (~12 с)
npx quartz build --serve         :: локальный сервер http://localhost:8080 (НЕ /normcontrol-kb/)
git add -A && git commit -F C:\path\to\msg.txt
set GIT_TERMINAL_PROMPT=0&& set GCM_INTERACTIVE=never&& git push https://github.com/frinog1-a11y/normcontrol-kb.git main
```

- SSH нет (`~/.ssh` отсутствует) → пуш только по HTTPS, учётные данные уже сохранены в Git Credential Manager.
- `git push` может быть отклонён: конвейер задач добавляет коммиты → `git pull --rebase origin main`, затем push.
- Коммит-сообщения по-русски передавай **через файл** (`-F`): в cmd кавычки и тире ломают команду.
- Пуш по явному URL **не обновляет** `origin/main` → чтобы проверить, что реально уехало, делай `git fetch` + `git show origin/main:<файл>` (или смотри raw-файл на GitHub).

## 5. Грабли (проверено практикой)

1. **`<script>` внутри markdown запрещён.** Сборка экранирует содержимое инлайн-скрипта (`"` → `&quot;`, `<` → `&lt;`). Поэтому логика игры живёт в `quartz/static/games/echelon.js`, а в заметке только `<script src="static/games/echelon.js"></script>` (такой тег проходит целым).
2. **Кодировка/BOM.** Файлы создавай инструментами редактора (UTF-8); `type a.md > b.md` в cmd добавляет BOM и ломает сборку.
3. **CRLF.** `content/*.md` в CRLF: многострочные `old_text` могут не совпасть → используй однострочные якоря.
4. **`node -e "..."` в cmd почти всегда ломается** (кавычки). Пиши временный `.js` в `%TEMP%` и запускай `node файл.js`.
5. **Браузера в системе нет** → визуально не проверить. Вместо этого: (а) `npx quartz build` + проверка собранного HTML/CSS/JS скриптом; (б) функциональные тесты «на заглушках» — код берётся из файла или из шаблонной строки (`afterDOMLoaded = \`...\``) и запускается в Node с самодельными `document`/`canvas`/`AudioContext`(примеры лежат в`%TEMP%`: `nck_ec2.js`, `nck_secret_test.js`, `nck_game_test.js`).
6. **Адреса:** листовая страница — без слэша (`/normcontrol-kb/echelon`), папка — со слэшем (`/normcontrol-kb/02_Ошибки/Обозначения/`); `/page/` для листа даёт 404.
7. **Деплой не мгновенный:** 2–8 минут; браузер кэширует `static/contentIndex.json` (проводник и поиск) → нужен `Ctrl+Shift+R`.
8. **`gh` CLI не установлен**, а сохранённый токен имеет только `repo, user, workflow` → Projects v2 через API недоступны (нужен `project`-скоуп). Доску и её workflows настраивать только руками в браузере.
9. **Скрытые страницы:** `quartz/util/hidden.ts` (`HIDDEN_SLUGS`) убирает страницу из поиска, графа, проводника, sitemap и RSS; `Head.tsx` добавляет `noindex`. Игра `/echelon` открывается прямым URL, секретной частицей в фоне или кодом `E-C-H-E-L-O-N`.
10. **Секреты:** ключ ИИ только в `Settings → Secrets and variables → Actions → LLM_API_KEY`; в файлах его нет (проверено поиском). Логи ИИ проходят через `scrub()`.

## 6. Открытые вопросы (что делает пользователь руками)

1. **Доска приватная.** `https://github.com/users/frinog1-a11y/projects/1` отдаёт 404 без авторизации → сделать `… → Settings → Visibility → Public`, иначе ссылка «🗂 Доска задач» открывается только у владельца. На ключ это не влияет (ключ в секретах, доска его не показывает).
2. **Лимит расходов ИИ.** У DeepSeek жёсткого лимита в настройках нет — ограничение делается минимальным балансом без автопополнения. Если нужен жёсткий лимит: завести ключ OpenRouter (`sk-or-…`) с полем Limit и заменить секрет `LLM_API_KEY` — код сам определит провайдера по префиксу.
3. **`content/05_Примеры/` пуст** — можно добавлять сканы «плохо/хорошо».
4. **27 документов без обратной ссылки** от карточек ошибок (скриптовый аудит связей) — если нужно, добавить ссылки.
